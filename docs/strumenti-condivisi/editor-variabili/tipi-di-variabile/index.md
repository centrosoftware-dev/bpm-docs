# Tipi di variabile

Il tipo determina quali valori può contenere una variabile, come viene presentata e quali proprietà aggiuntive sono disponibili.

L'elenco attuale dei tipi e delle relative proprietà deve essere verificato con lo studio dettagliato delle configurazioni reali. Le descrizioni già disponibili sono raccolte negli [attributi delle variabili](../attributi.md#tipi-di-variabili).
