# Connettori

Percorso: **Configurazione > Connettori**.

Un connettore è un componente tecnico che mette a disposizione integrazioni con sistemi esterni oppure funzioni di utilità interne. Non tutti i connettori realizzano un'integrazione.

Questa sezione documenterà il catalogo dei connettori e le rispettive configurazioni, comprese le connessioni a database e servizi esterni.
