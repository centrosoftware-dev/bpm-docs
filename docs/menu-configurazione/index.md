# Menu Configurazione

Il **Menu Configurazione** raccoglie le configurazioni BPM che non appartengono direttamente a un modello di processo o a una classe documentale.

La documentazione segue la navigazione dell'applicazione attuale, anche quando l'organizzazione delle funzioni dipende da ragioni storiche. Ogni pagina riporta il percorso nell'interfaccia per rendere immediato il collegamento tra applicazione e manuale.
